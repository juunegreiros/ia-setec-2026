# Planos

Cada plano divide um objetivo em **steps**. No modo Linear, o plano é um
**ticket do Linear**; no modo local, é um número (`1`, `2`…). Cada step vira um
slice com as skills `create-slice` ou `create-slices`.

- Criar: [`/start-new-plan`](../../../.cursor/skills/start-new-plan/SKILL.md) com a URL (ou o nome) do projeto e o título do plano.
- Retomar ou alterar: [`/continue-plan`](../../../.cursor/skills/continue-plan/SKILL.md) com o ID do plano.
- Modelo: [`../../templates/plan.md`](../../templates/plan.md).
- Nome do arquivo: `<id>-<titulo>.md`, ex.: `gam-12-pedidos-na-api.md` ou `1-pedidos-na-api.md`.
