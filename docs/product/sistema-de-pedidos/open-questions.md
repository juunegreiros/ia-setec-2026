# Dúvidas em aberto — Sistema de pedidos

1. **Quantidade zero enviada direto à API (R3, E3).** Hoje a regra diz que a
   API descarta o item e segue com os outros. A alternativa é rejeitar o pedido
   inteiro, como acontece com quantidade negativa (R4). Até a resposta, vale o
   comportamento descrito na R3.
